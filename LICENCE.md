## 🧩 About

**Polygon Client Companion** is a curated list of Polygon open-source tools:

- **Overlays** — on-screen helpers, layout notes, radar view, config panel
- **Quality-of-Life Helpers** — HUD tweaks, input notes, session tracker
- **Research Notes** — frame studies and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Config Panel — tune overlay options live
- Radar View — visualize nearby activity for study
- Session Notes — record and review match runs

- HUD Editor — rearrange on-screen elements
- Custom Theme Notes — organize color presets
